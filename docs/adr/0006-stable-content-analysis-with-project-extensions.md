# Combine a stable content analysis card with project extensions

Every selected article will receive a stable Content Analysis Card covering audience, communication goal, narrative, structure, presentation format, brand expression, transferability, evidence status, and risk. Research Projects may add Project Analysis Extensions derived from their confirmed briefs, preserving cross-project comparability without forcing regulated or industry-specific questions into a universal schema.

## Consequences

- Core analysis fields require explicit versions as their definitions evolve.
- Project extensions must identify the brief version and analytical question that created them.
- Facts, model inferences, uncertainty, and recommendations remain distinguishable in both core and extended analysis.
