# Separate benchmark patterns from owned performance evidence

MediaHunter will use benchmark articles to identify content patterns and the user's own WeChat backend exports to validate performance. Competitor readership, sharing, and conversion metrics must not be fabricated or treated as observed facts when unavailable, because operational recommendations must preserve the distinction between public evidence, inference, and owned-account measurement.

## Consequences

- Reports must label facts, inferences, and recommendations separately.
- Benchmark scoring cannot require unavailable engagement metrics.
- Owned-account data import and metric definitions are part of the analysis foundation, not an optional reporting add-on.
