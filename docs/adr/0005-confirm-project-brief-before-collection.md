# Confirm the project brief before starting collection

Each Research Project begins with free-form input that the Operations Skill structures into a Project Brief, followed by focused questions for material gaps and explicit user confirmation. Project-specific discovery and collection start only from a confirmed brief, preventing ambiguous audience, timing, compliance, or deliverable assumptions from generating a large but unusable evidence set.

## Consequences

- Original requests and revised brief versions must remain traceable.
- Only confirmed brief versions may launch or materially redirect project collection.
- Follow-up questions should target decisions that change research direction rather than enforce a generic form.
