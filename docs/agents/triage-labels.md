# Triage Labels

工程 Skills 使用以下五种标准 triage 角色。本地 Markdown 任务通过文件中的 `Status:` 行记录对应状态。

| Matt Skill role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待补充必要信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施或决策 |
| `wontfix` | `wontfix` | 已决定不处理 |

Skill 提及 triage 角色时，使用表中对应的本地状态值。
